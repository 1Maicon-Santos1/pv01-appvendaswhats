# Marca

Coloque o logotipo aqui como `logo.svg` (preferido) ou `logo.png`.

Ele é usado no cabeçalho e no rodapé. Sem arquivo, a página desenha uma marca
tipográfica com o nome configurado em `src/config/site.ts` → `BRAND.name`.

Tamanho de exibição: 150 x 32 px (a imagem é ajustada com `object-contain`).

O favicon é separado: `src/app/icon.svg`.
